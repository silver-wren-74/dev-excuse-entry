One funny single-line excuse a developer gives when code breaks in
production — under 200 characters, written by `main.py` to
`/output/entry.txt`:

> It worked in staging — production just runs the tests I skipped, in
> front of the customers, at 4:59 p.m. on a Friday.

The classic "it worked in staging" defence, turned into a confession:
the bug is not in the code, it is in the tests the developer skipped —
and production runs them live, in front of the customers, at 4:59 p.m.
on a Friday.

## Run

```sh
python3 main.py   # writes /output/entry.txt (117 characters, 1 line)
```
